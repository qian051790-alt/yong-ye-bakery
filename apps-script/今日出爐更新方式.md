# 今日出爐更新方式

網站會讀取 Google Sheet 裡名為「今日出爐」的分頁。

最簡單的填法：

| 今日出爐 |
| --- |
| 生吐司 |
| 餐包（可混搭） |

每天只要改這個分頁的品項，網站就會讀最新內容。

也可以加上這些設定列：

| 標題 | 今天可先詢問的品項 |
| 狀態 | 每日更新 |
| 備註 | 實際出爐品項會依當日訂單、發酵與備料狀況調整。 |
| 生吐司 | |
| 餐包（可混搭） | |

如果想保留完整品項表，也可以用兩欄開關：

| 顯示 | 品項 |
| --- | --- |
| TRUE | 生吐司 |
| FALSE | 餐包（可混搭） |
| FALSE | 蛋糕吐司 |
